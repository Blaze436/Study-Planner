## Concept Notes (Not Planned Features)

### Utility vision — canvas over tool
The long-term direction is that the app is a canvas for personal planning systems, not a fixed workflow. Users compose primitives into their own methods. This is the *vision*, not the MVP. Any feature that supports users inventing their own workflows belongs here first.

### Paper's affordances to preserve
- Visibility of the whole week at a glance
- Deliberate action required to change anything (no accidental edits)
- Physical presence — the notebook was always there

Translate these to digital where possible. Don't try to copy the medium.

### The "personal creation" factor
Paper felt meaningful partly because the user spent manual time creating it. This is hard to replicate digitally. Possible angles:
- Encourage users to name their own blocks and goals richly
- Resist adding default categories or templates
- Let the app "grow" with the user rather than shipping pre-set workflows
